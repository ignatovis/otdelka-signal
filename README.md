# Проект: Отделка SIGNAL

## Описание
Шаблон отчётности по отделочным работам для системы SIGNAL. Строительный контроль (СК) еженедельно вносит фактические объёмы выполненных работ, данные автоматически агрегируются в отчёт и карточки дашборда.

## Файлы

| Файл | Назначение |
|------|-----------|
| `01_Оригинал` | Исходный файл-образец (только для лобби, ручной ввод, без формул) |
| `02_Финальная версия v4` | **Рабочий файл.** 6 листов, два варианта ввода, полная цепочка формул |
| `03-05_Промежуточные` | Версии v1-v3 (история итераций) |
| `build_otdelka_v4.py` | Python-скрипт генерации файла (openpyxl). Запуск: `python build_otdelka_v4.py` |

## Архитектура v4

```
СПРАВОЧНИК (план, развесовки)
       |
       +---> ВВОД (вариант А для СК - плоская таблица, 5 колонок)
       |         |
       +---> ФАКТ-листы (вариант Б для СК - широкая таблица)
       |         |
       +---> ОТЧЕТ (автоматический, ФАКТ + ВВОД через SUMIFS)
                  |
                  +---> SIGNAL (карточки дашборда, 13 категорий x 3 типа)
```

## 6 листов в файле

1. **СПРАВОЧНИК** - единый источник: 13 категорий, плановые объёмы, развесовки (черновая/чистовая x пол/стены/потолок/меблировка). Валидация и условное форматирование.

2. **ВВОД** - плоская таблица для СК. 48 недель x 26 строк/неделю. Столбцы: Дата|Тип|Код|Категория|Пол|Стены|Потолок|Мебл. Текущая неделя подсвечена жёлтым. Столбец-чеклист.

3. **ФАКТ - ЧЕРНОВАЯ ОТДЕЛКА** - альтернативный ввод в широком формате. 13 категорий x (Пол/Стены/Потолок). Итого = SUM-формулы.

4. **ФАКТ - ЧИСТОВАЯ ОТДЕЛКА** - аналогично. 8.2.1 лобби имеет доп. столбец "Меблировка".

5. **ОТЧЕТ** - автоматический. Факт = SUM(ФАКТ) + SUMIFS(ВВОД). Процент = Факт/План. Взвешенный % через развесовки из СПРАВОЧНИК.

6. **SIGNAL** - 39 карточек (13 категорий x Общая/Черновая/Чистовая). Факт взвешен по развесовкам. Конфигурация: Статус, Гистограмма, По месяцам, Дата отчёта.

## Правила использования

1. СК выбирает ОДИН способ ввода: ВВОД или ФАКТ-листы. Не оба для одной недели/категории.
2. Развесовки и плановые объёмы менять только в СПРАВОЧНИК.
3. Даты: первая дата ручная, остальные = предыдущая + 7.
4. Дата отчёта в SIGNAL: ячейка B1, можно заменить на =СЕГОДНЯ().
5. Формулы в Excel отображаются на русском (СУММ, ЕСЛИ, СУММЕСЛИМН) автоматически.

## История изменений от оригинала

| Что было | Что стало |
|----------|-----------|
| 4 листа, только лобби в SIGNAL | 6 листов, 13 категорий в SIGNAL |
| Разная структура ФАКТ-листов | Единая структура по категориям |
| Ручной дубль данных в ОТЧЕТ | ОТЧЕТ 100% на формулах |
| Факт в SIGNAL без развесовки | Взвешенный факт через СПРАВОЧНИК |
| Даты вбиты вручную | Формула = предыдущая + 7 |
| Нет Меблировки в весах | Столбец Чист:Мебл. в СПРАВОЧНИК |
| Нет валидации | Проверка сумм весов, ограничения ввода |
| Один способ ввода (широкая таблица) | Два варианта: ВВОД (простой) или ФАКТ (широкий) |
