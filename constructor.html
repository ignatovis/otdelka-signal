Отделка для SIGNAL

Конструктор v14
Как пользоваться конструктором
1. Заполните параметры проекта: даты, кол-во недель, площади
2. Вкладка «Справочник» — задайте вес черновой / чистовой отделки для каждой категории
3. Нажмите «Скачать Excel» — сгенерируется файл со всеми листами ПЛАН/ФАКТ/ОТЧЕТ/SIGNAL
4. В Excel заполняйте площади (м²) понедельно на листах ПЛАН/ФАКТ
Параметры проекта
Дата начала СМР по отделке согласно ГРП (график реализации проекта)
Дата публикации первого отчёта в SIGNAL
Длительность СМР по отделке в неделях согласно ГРП
Подземная часть — площади (м²)
Общие площади категорий подземной части (8.1.x). Если данные отсутствуют — оставьте 0.
Корпуса (надземная часть)
Каждый корпус получит свои листы ПЛАН/ФАКТ. Укажите площади (м²) по категориям надземной части (8.2.x) для каждого корпуса. Если данные отсутствуют — оставьте 0.
Развесовка черновой / чистовой отделки
Для каждой категории работ укажите вес черновой и чистовой отделки. Сумма весов должна равняться 1.0.
Формула взвешенного процента: Факт% = (Черн_факт/Всего * Вес_черн) + (Чист_факт/Всего * Вес_чист)
Секция «Подземная часть» — общая для всего объекта. Каждый корпус имеет свою секцию надземной части с индивидуальными весами.
