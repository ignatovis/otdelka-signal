Отделка для SIGNAL

Конструктор v11
Как пользоваться конструктором
1. Настройте параметры ниже: даты, площади, корпуса
2. Во вкладке «Справочник» проверьте/измените веса категорий и распределение по поверхностям
3. Нажмите «Скачать Excel» — файл содержит листы ПЛАН и ФАКТ для каждой части и корпуса
4. В Excel заполняйте площади (м²) понедельно на листах ПЛАН/ФАКТ
5. Лист SIGNAL автоматически рассчитает взвешенный прогресс для визуализации
Параметры проекта
Дата начала — первая дата отчёта в SIGNAL, входящая в период плановых сроков реализации.
Дата отчёта — дата формирования первого отчёта (ячейка A2 листа SIGNAL).
Кол-во недель — горизонт планирования (сколько строк-недель на листах ПЛАН/ФАКТ).
Подземная часть — площади (м²)
Площади категорий подземной части (8.1). Используются в СПРАВОЧНИК для расчёта весов «подзем/надзем».
Корпуса (надземная часть)
Каждый корпус получит свои листы ПЛАН ЧЕРН/ЧИСТ и ФАКТ ЧЕРН/ЧИСТ. Площади по 7 категориям надземной части (8.2) определяют веса корпусов.
Цепочка весов (4 уровня)
Поверхности (Пол/Стены/Потолок/...) → Тип отделки (Черн./Чист.) → Корпус → Часть (Подзем/Надзем) → Итого
Каждый уровень суммируется в 1.0. Изменяйте веса и распределения в таблице ниже — они запишутся в лист СПРАВОЧНИК.
Справочник категорий отделки
Черновая: 3 поверхности (Пол/Стены/Потолок). Чистовая: 5 поверхностей (Пол/Стены/Потолок/Запол./Мебл.). Суммы = 1.0
Как заполнять Excel после скачивания
• Листы ПЛАН ЧЕРН/ЧИСТ — плановые площади (м²) по неделям для каждой категории и поверхности
• Листы ФАКТ ЧЕРН/ЧИСТ — фактически выполненные площади (м²) по неделям
• Лист ОТЧЕТ — автоматическая сводка по факту
• Лист SIGNAL — взвешенный прогресс для визуализации (формулы, не трогать)
• Категории с нулевой площадью (План м² = 0) можно не заполнять
